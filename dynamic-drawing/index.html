Dynamic Drawing

Dynamic Drawing

A drawing tool where the picture is driven by data. It follows Bret Victor's talk Drawing Dynamic Visualizations (2013): a spreadsheet and a vector drawing tool stapled together.

Data

Variables are expressions, worked out in dependency order like a spreadsheet. Arrays do arithmetic element by element, so powerKw * sunHours is an array too. Reductions like max(a), sum(a), count(a) turn an array into a number. Drag a chip from under a variable into any field to use it.

Or drag a chip onto a shape on the canvas, like routing an LFO to a knob. Dropped on a rectangle's top or bottom handle it scales the height about the opposite edge, on a side handle the width, on a corner both, on a circle its size, on a line's end its length, on a label its text. An array is divided by its largest element, so the biggest value fills the shape and, in a loop, each copy gets its own. If the step you're on already scales that shape about that point, the drop rewrites it.

Steps

Every drawing action records a step. Every number in a step is an expression you can edit, or drag sideways to scrub. Inside a loop, an array means its element for this time round, and i is the iteration. So scaling a bar by energy / max(energy) makes each bar its own height.

Snapping

While drawing, the yellow dots are magnets: corners, edge midpoints, centers, ends. Points along an edge snap too. Snapping records a relationship, "from the guide's top-left", not a position, so when the data moves the guide, everything drawn from it follows.

Guides and loops

A guide (G) is a shape that helps construct the picture but isn't part of it: it draws blue and dashed. Select some steps (shift-click) and press Loop to repeat them. The picture shows the state after the current step. ↑ ↓ walk through the steps as they ran, and ← → go to the same step in the previous or next iteration. New steps go in right after the current one, so you can draw inside a loop while looking at one iteration.

A shape's name means its latest copy. Inside a loop, a shape drawn later in the loop body still means last time's copy, which is how a line joins each sample to the one before it. Snap to an older copy on the canvas and the step remembers how far back it was.

Pictures inside pictures

A project holds several pictures. The picture tool draws one inside another, like a shape. The inner picture's variables become settings the outer one can override (pass it other data, a color, a width), and its measurements, expressions worked out after it is drawn, can be read from outside as here.total. A picture can draw itself: the tree example does, down to a fixed depth. Steps inside an If run only when its condition isn't 0.
